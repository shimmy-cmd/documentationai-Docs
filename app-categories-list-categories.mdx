## Overview

`appCategories.list.categories` is a Convex query that returns the set of app categories available to the authenticated user.

<Callout kind="info">

**Type: Query** — This function runs as a Convex query and requires the user to be logged in.

</Callout>

## Purpose

Use `appCategories.list.categories` to load the canonical list of app categories (names or tags) from the Convex backend. The function is implemented in `convex/appCategories/list.ts`, where it reads category data from the database for the current authenticated user.

On the frontend, the `useAppCategories` hook in `src/hooks/useAppCategories.ts` calls `useQuery(api.appCategories.list.categories)` to retrieve these categories reactively. The App Store UI then uses this list to render category filters and enable users to browse or filter apps by category. This keeps the filtering options in the interface aligned with the categories stored in the backend.
