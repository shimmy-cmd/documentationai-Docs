## What it does

<Callout kind="info">

Shomri is a managed app store for iOS devices under MDM supervision. Instead of using the native Apple App Store directly, users browse, install, and request apps through a controlled web interface that enforces device- and role-specific policies.

</Callout>

Shomri replaces the open-ended App Store experience with a policy-aware catalog tailored to each supervised device. Parents, mentors, organizations, and self-managed users see different apps and controls based on their role and the device configuration.

The Shomri web app runs inside a native iOS container, which lets it trigger system-level install and update flows while still rendering most of the UI in a browser environment.
