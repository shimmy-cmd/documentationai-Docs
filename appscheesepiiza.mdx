## Overview

`apps.list.updates` fetches installed app version data for a specific device and returns which apps have newer versions available. Use it to drive app update indicators in the App Store experience.

<Callout kind="info">

**Type:** Action

</Callout>

## Purpose

`apps.list.updates` checks Jamf data for a given device and returns a mapping of installed apps to the latest known versions, or `null` when update information is not available. The app-store-project calls this action from `useDeviceLibrary` and `useInstalledApps` hooks to look up update status for the device identified by its serial number. The result lets the app highlight which installed apps are out of date, so users can see and prioritize pending updates for that device.
